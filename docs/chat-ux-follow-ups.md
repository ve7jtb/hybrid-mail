# Google Chat UX follow-ups

- Completed 2026-11-20: Google Chat → Send bundle now has a full-width subject field with larger text and a bold “Subject (inside encrypted bundle)” label above it. Encryption has its own row. Explanatory text distinguishes the protected subject from Google's visible Chat caption. Turning encryption off changes the label to “Subject (inside signed bundle)” and makes the lack of encryption explicit. The label is also associated with the field for accessibility.
